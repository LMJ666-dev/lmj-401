任务一 · 提示词工程师把四条需求“翻译”给 AI

目标：让 AI 生成 new Swiper('#wySw4', {...}) 的初始化配置，覆盖四条需求。

① 需求拆解（写提示词前的准备）

中文需求对应 Swiper 参数
无缝循环，最后一张能接回第一张loop: true
每 3.2 秒自动翻页，且用户手动滑动后不停止autoplay: { delay: 3200, disableOnInteraction: false }
圆点分页器可点击跳转（页面里有 4 个分页器，必须指定本页唯一元素）pagination: { el: '#wyPag4', clickable: true }
初始效果为 3D 立方体effect: 'cube'（可加 cubeEffect 微调）

② 第 1 轮提示词（粗略版）

帮我用 Swiper 11 写一段初始化代码，选择器是 #wySw4。
要求：无缝循环、自动播放、有分页器，初始效果用 cube。请直接给完整代码。

③ 第 1 轮 AI 回答（有遗漏，已原样保留）

new Swiper('#wySw4', {
  loop: true,
  effect: 'cube',
  autoplay: true,
  pagination: { el: '.swiper-pagination' }
});

我验证后发现 4 个问题：

  • ① autoplay: true 实际间隔是默认 3000ms，不是要求的 3200ms；
  • ② 没有写 disableOnInteraction: false，默认手动滑动后就停播，不符合“手动操作后不停止”；
  • ③ 分页器写的是通用类 .swiper-pagination，页面有 4 个轮播会全部命中，必须写 #wyPag4；
  • ④ 没有 clickable: true，圆点只能看不能点。

④ 第 2 轮提示词（把每个问题说清楚）

上一版有 4 个问题，请逐条修正后重新给出完整代码：
1. autoplay 必须是 3200 毫秒，不是默认 3 秒；
2. 用户手动滑动后自动播放不能停止，需要 disableOnInteraction: false；
3. 页面里共有 4 个轮播，分页器必须精确绑定 #wyPag4，并且 clickable: true；
4. effect 保持 cube。其他配置不要删。

⑤ 第 2 轮 AI 回答（最终版，已粘贴进作业页）

new Swiper('#wySw4', {
  loop: true,
  speed: 800,
  effect: 'cube',
  autoplay: {
    delay: 3200,
    disableOnInteraction: false
  },
  pagination: {
    el: '#wyPag4',
    clickable: true
  },
  cubeEffect: {
    shadow: true,
    slideShadows: true,
    shadowOffset: 20,
    shadowScale: 0.94
  }
});

⑦ 答辩准备

问：第一版提示词漏掉了哪个需求？

严格说四条都写了，但写得不够具体：没写 3200ms、没写“手动滑动后不停”、分页器没指定唯一容器、也没要求圆点可点。模糊的“自动播放 / 有分页器”被 AI 按默认值实现了。

问：第二轮是怎么“说清楚”的？

把每条需求换成可验证的量化条件：给出毫秒数 3200、给出参数名 disableOnInteraction: false、给出唯一选择器 #wyPag4 和 clickable: true，并要求“逐条修正、其他配置不要删”，避免 AI 自由发挥。

问：AI 第一次给的代码错在哪？

① autoplay 用布尔值，间隔不可控；② 缺少手动交互后继续播放的配置；③ 分页器选择器太宽泛，4 个 Swiper 会抢同一个元素；④ 圆点不可点击。

任务二 · creative 仿写第 7 种效果：电影胶片墙

先打开官方示例 swiper/demo/257-effect-creative.html，其中第 3 个实例的写法最接近“侧向让位”的胶片墙：

effect: 'creative',
creativeEffect: {
  prev: { shadow: true, translate: ['-20%', 0, -1] },
  next: { translate: ['100%', 0, 0] }
}

① 我改造后的电影墙参数

// 函数功能：为 creative 效果提供自定义参数，上一张缩小左移带角度，下一张放大从右侧进场
creativeEffect: {
  prev: {
    shadow: true,
    translate: ['-25%', 0, -120],   // 向左退 25% 宽度，Z 轴后移 120px
    rotate: [0, 0, -12],            // 逆时针倾斜 12 度
    scale: 0.82,                    // 缩小到 82%
    opacity: 0.55                   // 变暗，像退到背景
  },
  next: {
    shadow: true,
    translate: ['100%', 0, 0],      // 从右侧一整屏外推进来
    rotate: [0, 0, 12],             // 顺时针倾斜 12 度
    scale: 1.12                     // 放大到 112%，有迎面感
  }
}

作业页演示四的第 7 个按钮「creative 电影墙」即调用这组参数：点它，上一张会缩小、左移、倾斜并压暗，下一张从右侧放大推进，形成电影胶片墙的纵深。

② prev / next 各控制什么（自己的话）

键控制对象效果
prev当前幻灯片“之前的那一张”（也就是正被翻走的上一张）它离场时的位移、旋转、缩放、透明度，表现为向后退到画面外
next当前幻灯片“之后的那一张”（即将进场的新一张）它进场时的位移、旋转、缩放，表现为从画面外推到正中

③ 答辩准备

问：transform 里的百分号是相对谁的？

translate 的数组是 [x, y, z]。x 写百分比时，相对的是“幻灯片自身的宽度”；y 写百分比时，相对的是“幻灯片自身的高度”；z 只能写像素值，不是百分比。所以 '-25%' 表示向左移动自身宽度的 25%，不是容器的 25%。rotate 的三个值是角度（deg），不是百分比。

问：改一个数值让卡片转 20 度，怎么改？

把 prev.rotate 的 [0, 0, -12] 改成 [0, 0, -20]（next.rotate 同步改成 [0, 0, 20]），Z 轴旋转就从 12 度变成 20 度；刷新或重建实例即可看到倾斜更明显。

② 超纲能力：keyboard 键盘控制

// 任务三超纲能力：键盘左右方向键控制，onlyInViewport 表示轮播进入视口才响应
keyboard: {
  enabled: true,
  onlyInViewport: true
}

作业页的演示四已启用：滚动到演示四可见时，按键盘 ← → 即可切换幻灯片。选 onlyInViewport 是因为页面有 4 个轮播，只让当前看得到的那个响应键盘，避免互相抢事件。

③ 答辩四连问准备

问：这段代码什么意思？

keyboard.enabled: true 打开键盘控制模块；onlyInViewport: true 表示只有该轮播出现在视口内时才监听方向键，离开视口自动失效。左右方向键分别对应 prev / next。

问：AI 第一次给的结果哪里不对，你改了什么？

第一次 AI 只写了 keyboard: true，Swiper 11 要求对象配置，布尔值不生效；并且没加 onlyInViewport，页面滚到别处按方向键仍会翻动演示四。改为对象写法并补上 onlyInViewport: true 后正常。

问：新参数的作用？

enabled 是键盘模块总开关；onlyInViewport 把响应范围限制在“可见”状态，多轮播页面里尤其必要，属于避免事件冲突的行为约束。

问：现场把 delay 改成指定值并解释预期变化？

例如把 3200 改成 1500：每 1.5 秒翻一张，节奏明显加快；改成 6000：6 秒才翻一张，更从容。注意 delay 在实例创建时读取，改完后要重建实例，或在控制台执行 bzy_swiper4.params.autoplay.delay = 1500; bzy_swiper4.autoplay.start(); 才会生效。
